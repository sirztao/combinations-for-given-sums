# combinations-for-given-sums
# Invoice Subset Sum Solver

🔍 **问题背景**  
在一次采购中购买了 **23 件商品**，商家合并开具了发票，其中一张金额为 **¥6194.00**。  
需要从这 23 件商品的价格中，找出**所有可能的子集组合**（大小限制在 7～17 之间），使其**总和等于 6194.00（允许 ±0.01 浮点误差）**，以还原该发票可能包含的商品。

> 💡 注意：价格列表中存在重复值（如两个 245 元），但它们代表**不同的商品/票据**，因此必须视为独立元素，**不允许去重**。

| **健壮性差** | 无异常处理，路径硬编码易崩溃 | ✅ 捕获文件错误，提示用户创建目录 |

## 🧮 问题本质

这是一个经典的 **Subset Sum Problem（子集和问题）** 的受限变种：
- **输入**：23 个正实数（商品价格）
- **目标**：子集和 ≈ 6194.0
- **约束**：子集大小 ∈ [7, 17]，保留重复值，浮点容差 ±0.01

尽管是 NP-Hard 问题，但因 `n=23` 较小 + 高效实现，可在秒级完成全量搜索。
